How to use

Click or tap the sky to launch at that spot. It launches what you picked last (Fireworks, Chicken, Jug-o-BOOM or Cow), fireworks until you pick.

Check Boundaries to see where fireworks burst. Drag its edges or corners, or use the sliders, to change it.

import { Xploders } from 'xploders'

const show = new Xploders(document.querySelector('.sky'))
show.start()
show.launch('chicken')
show.launch('jug')
show.launch('cow')

Options, methods, the chicken, the Jug-o-BOOM and the cow: README on GitHub.
