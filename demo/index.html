How to use

Click or tap the sky to launch at that spot. It launches what you picked last (Fireworks, Chicken or Jug-o-BOOM), fireworks until you pick.

import { Xploders } from 'xploders'

const show = new Xploders(document.querySelector('.sky'))
show.start()
show.launch('chicken')
show.launch('jug')

Options, methods, the chicken and the Jug-o-BOOM: README on GitHub.
